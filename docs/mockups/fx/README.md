# 新卡触发特效 · 设计稿批(fx/)

> 本目录 = 15 张新卡「触发特效」的 HTML 动效设计稿。每页一卡,纯内联 CSS/JS、零外链、
> 打开即循环播放。**这是设计稿,不是实现**——落地时全部换成 Godot 程序化绘制。

## 特效设计原则(总纲)

1. **触发特效 = 结算链弹出的动效,单次 ≤ 0.6s**。demo 里的循环只是示意,
   实际每次触发只播一遍;循环周期里多出来的时间全是静息。
   (预支是唯一的三拍卡:借入 / 偿还 / 违约各是一次独立触发,各自 ≤ 0.6s。)
2. **不挡牌面**:特效以小丑牌卡位为锚点,向上、向外扩散;手牌区与缓存区永不被覆盖,
   数值弹出限卡位上方一行高。
3. **不加音频**:节奏感全部由动效时序承担——入场快(0~40%)、定格顿(40~70%)、
   消散缓(70~100%),与结算链「弹出 → 读到 → 让位」同构。
4. **全部程序化可画**:只用三类原语组合——**粒子**(点 / 碎片 / 流光)、
   **描边脉冲**(rim pulse / 沿边跑光)、**文字弹出**(数值 chip)。零位图素材。
5. **每张卡一个「视觉动词」**,与机制隐喻一致,禁止泛用星星粒子。
   判据:把 15 张的特效两两互换,玩家应当立刻发现不对。
6. **遵守全局美术**:黑底,光全部由光效层承担;暗玻璃 + 主色描边 + 外发光;
   只用五主色(青 `#1effec` / 粉 `#ff328d` / 紫 `#7642ff` / 金 `#ff9b2b` / 红 `#ff3632`),
   金币语义恒金。
7. **色注**:预支的「借入」需要一个信用色,五主色里没有纯绿,
   取青 `#1effec`(黑底上读作冷绿)承担「流入 / 信用」,红 `#ff3632` 承担「抽走 / 违约」。

## demo 页规格

- 720×360 黑底预览区(游戏为竖屏 720×1280,预览区取其中一段横条示意);
- 顶部一行 = 卡名 + 触发条件,次行 = 视觉动词;
- 循环周期 ≈ 2.4s(孤注/彩头隔次切换输赢两态;客串 3.4s 含谢幕半拍;预支 4.8s 三拍连播);
- 两个例外不受 0.6s 约束:**超级百搭**是商店购入时的一次性入库仪式(~1.4s),不在结算链内;
  **预支**的三拍各自 ≤0.6s,demo 连播只是为了讲完整个生命周期;
- 全部自包含:无外链字体 / 图片 / 脚本,字体栈 Rajdhani 优先、系统字体兜底。
