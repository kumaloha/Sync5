## 1. 🔴 必修(已去重合并,按玩家/结论影响排)

### 代码

**R1 · 8 张卡的升级是纯扣钱** ✓ `core/fx.gd:193-258` vs `:278`
六个操作码(`mult_from_target_factor` / `additive_face_value` / `additive_low_value` / `coins_factor` /
`additive_cache_top` / `chips_per_card`)在 `scale` 放大段之前就 `return`。`Joker.can_upgrade()` 只排除规则牌
⇒ vip / mirror / bassclef / warmtone / cooltone / undertone / bench / royalty 在商店挂升级报价、扣 4/7/11/16◆、
`level += 1`,结算一分不涨;bot 同样在升。`joker.gd:249-252`「放大只发生在 apply 一处,谁调谁拿到」是
**注释承诺了不存在的机制**。修:六个通道各乘 scale(mult 走 `1+(x−1)×scale`),`can_upgrade()` 对无放大通道的卡返回 false,
补 A/B 测试:遍历可升级卡断言满级 apply ≠ Lv1。

**R2 · 「再来一次」绕过 Director / min_run / 局数 / ctx** ✓(core 骨架 + view 编排两片交叉)
`view/phrase.gd:888 _reset_run(true)` → `run.reset()` → `roll_faces(face_seed)`,`run_index` 走缺省 −1;
主路径 `choose_character` 在 reset 之后还有 `_feed_director()` + `roll_faces(-1, _run_index)` + `note_run_started()`,
重开路径三样全没有。后果:`unlocked_at(id, −1)` 恒 true ⇒ 禁回第 2 局重开就能出现(正是 `director.gd` 注释点名的形状);
`Director.index_for(−1)` ⇒ 永远第 1 局状态;`director_ctx`/`face_ranking` 是上一局的快照;`runs_total`/`history` 分叉;
`Tape.begin` 少 `sess`/`tutorial` 键。修:抽 `_begin_run()` 让两条入口共用;`Run.reset()` 清两个字段并要求显式 run_index。

**R3 · 教学商店里花真金买的牌在 `tutorial_done` 被整排没收**(view 编排,置信高,购买路径为评审员追踪)
`view/phrase.gd:794` 无条件清四槽。教学段第 3 拍末 `shop_break` 开真商店,四槽已装满借展样品 ⇒ 任何购买走替换流:
付钱、拿样品的折半退款、装新卡;第 6 拍末新卡连样品一起删,退款留在钱包,`on_acquire` 写下的 deck 规则不回滚。
`t_tutorial` 零覆盖教学商店。修:没收只清 `_stage_tutor_props` 装进去的四个 id;补断言「教学商店买的卡带进正式局」。

**R4 · 资产页矩形下标与 roster 错位** ✓(渲染 + 骨架两片交叉)`view/honors.gd:80 / :347`
`_draw_assets` 对下架资产 `continue` 在 `_asset_rects.append` **之前**,点击却 `Asset.roster()[i]` 按矩形下标取 id
⇒ 第一件带 `season` 的资产一下架,它下面每行点下去都买成上一件并真扣宝石。`Asset.can_buy` 也不查 `on_shelf`。
现在 11 件全常驻所以潜伏。修:rect 与 id 成对存;`can_buy` 加 `on_shelf`。

**R5 · gate.gd 第三份判生死没乘 trilogy 的税 → trilogy 被错误豁免** ✓ `tools/gate.gd:537-574`
`_play_runs` 自算 `target = section_target_for × target_scale`,不乘 `Run.variety_mult`(runloop.gd:144 乘了)。
trilogy 的行为臂与基准臂逐位相同 ⇒「实测 0.0 ±0.0」是**结构性恒零**,随后进了 `faces.json weak_upper_bound`。
「规则在游戏里不在模型里」第 7 次,且被豁免表盖住。修:`_play_runs` 改走 `RunLoop`;trilogy 从豁免表摘出重测。

**R6 · 探针世界里没有 boon** ✓ `tools/runloop.gd:89-98`(`grep boon tools/` 零命中)
`RunLoop.play` 只设 `run_faces`,`run_boon` 永远 ""。双响(S4 每拍 +50%)、余响、聚光、返场在 sim/curve/gate/kit/price
全部不存在 ⇒ S4 目标分是在无 boon 的世界里反解的;STATUS「4 boon 全实装,gate.sh 全量绿」—— 门覆盖不到它。
修:`Opts.boon`(默认空保持逐字节不变)+ sim/curve 按游戏顺序掷 boon;或在 gates.md 显式登记为已知盲区。

**R7 · gate.sh 的单测判据只看一个 grep** ✓ `tools/gate.sh:99-105`
`grep -q ', 0 failed'`:丢退出码(注释「runner 不返回非零」是假的)、不数 `SCRIPT ERROR`/`^ERROR`、不看通过数、无超时
(一个域 parse 失败 ⇒ 永不 quit ⇒ 门无限挂起)。LESSONS 的「四条同时满足」在唯一要紧的地方没落地。

**R8 · Web 包混进约 57MB 非运行时资源** ✓(exclude_filter 已核对)`export_presets.cfg:84`
漏排 `assets/characters/source/*`(48 张原画 43MB,唯一消费者是美术管线)、`assets/reference/*`(12MB)、7 张退役小丑原画、

08-12「iOS 内存止血」只排了小丑 source,角色 source 漏了。修:补过滤;`build/` 与 `assets/reference/` 放 `.gdignore`。

**R9 · TapTap 包 debug 签名 + 占位包名 + dev 版本**(数据片读了 apk)`export_presets.cfg:41-50`
`CN=Android Debug` / `com.sync5.dev` / `0.1.0-dev`,`launcher_icons` 全空。包名上传后不可改。

**R10 · 券是伪配置化**(数据片)`data/tickets.json` ↔ `view/tray.gd:19` / `view/phrase.gd:1120-1150`
`scope` 只有测试读;`params.rerolls/hands` 无人读;托盘 `ORDER` 与 `_on_ticket_use` 按 id 字面量写死;

**R11 · sim A/A 抖动的根因候选** ✓(形状吻合,待 A/A 验证)`tools/runloop.gd:90` ↔ `core/run.gd:29,143`
