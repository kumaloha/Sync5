# 卡片 EV 账本(仪器读数,手改无效 —— 重刷:`godot --headless --path . --script res://tools/cf.gd`)

反事实重放:同一拍跑两次 `Settle.run` 只差 `joker_slots`,差值 = 这张卡的边际贡献。
样本:**19 局 / 250 拍**真人 Tape(筛法与 `tools/probbook.py::_qualified` 同一份)。

**两个口径都要看**:
- `EV空构筑` —— 卡装在空牌组上。所有卡同一基准,**可比**;
- `EV真实构筑` —— 装在玩家**当时的牌组**上。`numbers.md §8.1` 用的就是它,**定价看这个**。
  两者能差几倍(倍率链均值 6.7~10.3,乘法类卡在真实构筑里被放大)。

⚠ **绝对值有系统偏差,只用相对排序** —— 无条件卡「灯牌」按 §3.1 定义就是地板,
而它读不到 1.00×。⇒ **以灯牌归一后再比**,且**只在族内比**(奖励分族与改基族差 3.5 倍)。

⚠ `EV早段`(S1-2)/`EV晚段`(S3-4)是 CLAUDE.md「奖励分前期是神、后期过气」那句的检验位 ——
2026-08-28 实测**两头都反**(奖励分晚/早 = 2.50,改基 0.91),那句话只对固定数额成立。
