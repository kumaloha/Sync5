## 0. 读这张表之前的五条口径

1. **目标带**:support 局贡献 **+800 ~ +2500**(方向值)。排序 = 离带的距离,偏离最狠的在最上面。
   Target 族不适用这条带(它们按 jokers.md 覆盖面两层原则 + 牌型倍率 v3 的 `P(≥k|b) × (1+λ·CV)` 标定),
   但仍按分差排进表里看离散度 —— ⑥ 批的总目标是把 70 倍离散度收敛到 3 倍量级。
2. **kit 是 08-27 门的旧世界读数**。四张卡/族已在门后改动,读数标 ⚠**过期**:
   **拆迁**(弃6×3.5 → 弃4×2)· **和弦/和声/静场**(条件已放宽;静场数额同步 0.4→0.15)·
   **镜面**(已加 target_streak 连续两拍条件)· **包厢**(0.2→0.35/张,feedback #5)。
   另外**牌型倍率 v3 已重标** ⇒ 全部 score 通路读数都是旧倍率世界的,Target 族尤甚 —— 本稿的
   建议以「方向 + 幅度」为主,落地前逐张 `kit` 复测是 SOP 第 5 步,不能省。
3. **kit 基线不止一个**:score 臂空装基准 **3882**;镜面在 twin 臂(基准 **17546**,分差尺度大一档);
   灌铅骰在 allin 臂(基准 **4909**);盲奏在 dimstage 环境(基准 **3826**)。% 列已按各自基线归一。
4. **经济 v2 改变了第④因子(条件成本)的世界**:弃牌 1◆/张(推翻弃牌免费)· 卡价平化 3◆ ·
   开局 10◆ · 主收入 kind_coins。两个连带:
   ① **吃弃牌的卡(黑胶/贝斯线/周转/拆迁/让位/早弃)条件成本剧变**,其中黑胶 v3 砍到 +1/弃的
   前提「弃牌免费」已不存在;② numbers.md §8.0 的稀有度地板线(50/75/110)是按 4/6/9◆ 推的,
   **卡价平化后这条线的推导基础失效**,rare 卡「贵所以该强」的溢价理由消失 —— 本稿按
   「rare = 低频高爆/构筑轴」而非「rare = 更贵」给建议。
5. **定价锚优先级:先验 > 真人 > bot**。kit 是 bot 读数 —— 凡 bot 与真人行为已知劈叉的条件
   (保型/早锁/持币),表里按真人锚给建议并注明,**不拿 bot 读数直接除**。λ(风险厌恶)归用户手感,本稿不代填。
