# TapTap 上架研究(2026-08-12)

> 结论先行:**咱们的形态(纯单机离线 + 无内购 + 免费)走「正式上线(试玩版)」,
> 免版号、免软著、免 ICP 备案。** 硬门槛只有两个:**防沉迷接入**(最大技术项)与
> **隐私合规**(政策页 + 弹窗)。TODO 发行线原来的假设(「试玩版免版号上架」)成立。
> 信源以 TapTap 官方开发者文档为准,末节列开放问题。

---

## 1. 资质矩阵(官方口径,决定路线)

| 游戏属性 | 必需资质 | 上线形式 |
|---|---|---|
| 联网+内购 | 版号、软著、ICP、防沉迷、隐私合规 | 正式上线 |
| 联网+无内购 | ICP、防沉迷、隐私合规 | 开放试玩 |
| 离线+内购 | 版号、软著、防沉迷、隐私合规 | 正式上线 |
| **离线+无内购(← 我们)** | **防沉迷、隐私合规** | **开放试玩** |

- 无版号 = 禁止任何收费/内购;可在大陆开放**预约**与信息展示;
  试玩版前台默认显示「关注」,不可选游戏状态。
- ⚠ 第三方(版号代办机构)有更保守的说法(「任何可下载都要版号」)——
  与官方矩阵冲突,**以开发者后台实际可选项为准**;吃不准就先发工单问客服。

## 2. 入驻(可立刻做,免费)

1. TapTap 账号完成**实名认证**;
2. 开发者中心申请**认证开发者(个人)**:身份证正反面扫描件、邮箱、手机号、
   **中文厂商名**(建议「xx工作室」后缀,不得全英文/冒用企业名),1-3 个工作日;
3. 新建游戏(「未发布」态,上限 20 个)→ 可先开**预约页**(不用包体、不用防沉迷)
   攒关注,同时并行做防沉迷集成。

## 3. 两个硬门槛

### 3.1 防沉迷(最大技术项)

- 官方要求:**提供包体下载就必须完善防沉迷**,审核要交**接入视频证明**;
- 路径 = TDS **合规认证 SDK**(实名+防沉迷),**依赖 TapTap 登录 SDK**
  (推荐 v3.29.0+ 可静默授权:玩家用 TapTap 账号里的国家认证实名信息,
  拒绝授权则手动填身份信息);
- 限玩规则(SDK 自动执行):未成年人仅周五六日与法定节假日 20:00-21:00;
- ⚠ **Godot 无官方 SDK**(官方支持 Unity/Android 原生/iOS/Cocos)——
  要把 **Android 原生 SDK 包成 Godot Android 插件**(GodotPlugin + gradle 自定义构建),
  估 2-4 天含调试。从 TapTap 商店来的玩家都有 TapTap 账号,登录依赖可接受。

### 3.2 隐私合规

- **隐私政策链接是「正式上线(试玩版)」的必填项**,且要过隐私安全合规检测;
- 要做:① 一页隐私政策(单机无采集,文本简单),托管在**国内可访问**处;
  ② 游戏内**首次启动弹窗**(同意/拒绝 + 链接),同意标记存 user://;
- 权限最小化:纯单机理论上可以零敏感权限,检测就好过。

## 4. 物料清单(审核细则口径)

| 物料 | 规格 |
|---|---|
| 图标 | 方图、**不自行裁圆角**、无误导角标 |
| 截图 | **实机画面 ≥50%**,概念图 ≤2 张,尺寸方向一致,不得重复单一 |
| 实机视频 | **必须**(开放试玩即要求);**>15s**(≤30min),**前 5 秒进核心玩法、核心玩法连续 >10s** |
| 文案 | 简体中文 |

竖屏 720×1280 正好适合手机录屏;截图探针(`tools/*_sheet.gd`)可出无 UI 遮挡的素材,
但「实机画面」以真机/模拟器录制为准。

## 5. 包体(Godot 侧出包清单)

- **包名先想好再传,不可直改**(工单才能换)——待定,形如 `com.<studio>.sync5`;
- **64 位必须**(arm64-v8a;可另带 armeabi-v7a);
- keystore:`keytool -genkeypair -v -keystore sync5.keystore -alias sync5 -keyalg RSA
  -keysize 2048 -validity 10000` —— **release keystore 丢了就永远不能更新,要备份**;
- Godot 4.6.2 Android 导出预设:签名、versionCode/Name、图标/启动图;
  防沉迷插件要走 **gradle 自定义构建**;
- 预约阶段可不传包;传包审核首审 1-3 日、更新 1 日内;物料+资质提审 5-7 天。

## 6. 行动清单(依赖排序)

1. **用户拍板**:中文厂商名 · 包名 · 隐私政策托管处(可 Gitee Pages / 自有域名);
2. 入驻认证开发者(1-3 工作日,等待期不阻塞后面);
3. 建游戏页 + 开**预约**(文案/图标/截图初版,不用包体) ←—— 最早的对外节点;
4. keystore + 导出预设 + 无 SDK 裸包真机验(TODO 发行线原有项);
5. **防沉迷插件**(TDS 合规认证 + TapTap 登录,Godot Android 插件,2-4 天)
   + 录接入视频;
6. 隐私政策页 + 首启弹窗(view 侧,文案进 data/ui.json);
7. 物料终版(实机截图 ≥50%、录屏 15s+ 前 5 秒核心玩法);
8. 提审「正式上线(试玩版)」(5-7 天)。

预约页最快本周可开;试玩版全链约 **2-3 周**(大头是防沉迷插件 + 提审周期)。

## 7. 开放问题(发工单问客服)

- 纯单机接合规认证 SDK 后产生网络调用,**是否因此需要 ICP 备案**?
  (官方有「测试游戏备案辅助证明」兜底,矩阵里离线+无内购未列 ICP);
- 「开放试玩」与「正式上线(试玩版)」在后台是否同一开关、能否直接从预约切换;
- 适龄提示(8+/12+/16+)是否需要自评材料。
