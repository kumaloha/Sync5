## 一、对抗代数

**盲注 = 「条件」+「惩罚」;小丑牌 = 「条件」+「激励」。**(用户 2026-08-25 拍板的公式)

关卡核心是盲注:玩家看到脸的那一刻,应该开始想「什么构筑好解」;
局内靠运气(手牌与小丑对上)与经营(金币分配让自己**选得到**想要的卡)完成构筑并吃分。

### 惩罚三型 —— 不同型吃的解法不一样

| 型 | 例 | 关键性质 |
|---|---|---|
| **禁止**(动作没了) | 限弃张数 · 时段锁操作 | **不可被抵消**:动作被拿走,给分补不回动作本身 ⇒ 禁止型要**少而贵** |
| **税**(分打折) | 重复出牌减半 · 指定花色减半 | 全部解法可用,含余量认罚 ⇒ 可以多而密 |
| **剥夺**(资源被偷) | 没收缓存 · 偷时间 · 遮信息 | 抵消 = 换个来源补资源 |

### 卡形三种 —— 「条件+激励」只是主体

| 形 | 例 | 设计约束 |
|---|---|---|
| **条件 + 激励** | 每弃一张加分 · 零弃牌给金币 | 主体,进三档矩阵(见三) |
| **无条件 + 改规则** | 万能牌 · 点数可当 ±1 用 · 两色并一色 | 「买来的错开」,万题通用 ⇒ **限量且贵** |
| **拍外条件 + 资源** | 持金币给倍率 · 每刷新商店永久成长 | 对所有脸恒错开(金币盲注不设的结构红利)⇒ **产出必须慢** |

## 二、解法只有四种(+一个地板)

玩家视角等效的类别必须合并(用户裁定:引导并入抵消、改底并入错开、溢出并入抵消、换阵=排期)。

| # | 解法 | 内容 | 层面 |
|---|---|---|---|
| 1 | **错开** | 脸咬不到我。天生(构筑不依赖那资源)或买来的(规则卡,限量) | 构筑 |
| 2 | **抵消** | 脸让我付的代价有东西赔。三个子型:**对症赔**(没达成条件的拍补分)· **改行为的报酬**(脸罚重复,卡奖变化——追着奖励走,罚落不到头上)· **余量认罚**(分厚,罚得起) | 卡面 |
| 3 | **利用** | 脸逼的行为恰好是我的条件(限弃的脸替零弃卡守戒);或惩罚事件直接触发收益(脸每触发一次给金币) | 卡面 |
| 4 | **调度** | 局级运营,一件事的两面:**排期**(雷段低投入认怂,爆发排别处)+ **换阵**(段间买进卖出,「这段我做谁」)。中途换卡是随机应变的极限操作、技术上限 | 局 |

- **抵消红线:只许赔一半上下。** 赔平 = 脸对该构筑变空气 = 换皮的钥匙。
- **余量认罚是合法路线**:运气极致(抽到复制、送分卡)靠蛮力碾过去**就该**可行——
  「好玩的超模保留,排他的超模处理」(原作原则)。仪器只防它成为唯一解。
- **调度依赖「开局亮整局四张脸」**;折半回收是换阵的税率阀门,租赁卡(超额数值、只活一段)是润滑剂。

### 解法 × 惩罚型 适用表

| 解法 \ 惩罚型 | 禁止 | 税 | 剥夺 |
|---|---|---|---|
| 错开 | ✓ | ✓ | ✓ |
| 抵消 | ✗ | ✓(限一半) | ✓(换源补) |
| 利用 | ✓(最肥沃:限制免费送条件) | ✓ | ✓(被偷前自己卖掉) |
| 调度 | ✓ | ✓ | ✓ |

## 三、三档矩阵 —— 不设钥匙,由数据推导

**「一张卡反制一张脸」= 商店彩票**(抽到就开锁,抽不到干瞪眼,中间没有构筑思考)——
专用对策卡不设。每张「条件+激励」卡对每张脸自动落进三档:

- **被克**:脸让条件做不成了;
- **避开**:条件不受影响——**解题主力 = 多张避开卡的组合**(条件仍做得成、奖励叠够数);
- **顺应**:脸逼的行为恰是我的条件——钥匙的唯一合法形态。

**三档由「卡的条件声明 × 脸的参数」自动推导,不靠手维护**;
配置期校验:每张脸「避开 ≥3 个条件族、顺应 ≥1」,不满足直接红。
旗别撞脸的雷是第零层(花色被遮就别做同花)。

## 四、归属边界 —— 什么住哪侧

1. **纯坏事只能做脸**:剥夺和税,玩家永远不会自选;卡不会削自己。
2. **五类只能做卡**:金币经济(拍板:金币不当惩罚通道)· 成长积累(脸只活一段,攒不起来)·
   商店使能(脸不出现在商店节拍)· 逐拍主动赌(自己选的方差是乐趣,强加的逐拍掷分是不公——
   脸只许**开局明掷一次**)· 复制与放大(脸手里没有「你的其他卡」这个对象)。
3. **行为奖惩是两面机制**:同一个条件,脸做罚、卡做奖(罚重复的脸 ↔ 奖重复的卡)。
   **模具**:每设计一张罚 X 的脸,顺手查「奖非 X」的卡存不存在——不存在就是一张现成的新卡。
   附判据:每个新机制先问「它能站哪侧」,再问「另一侧值不值得也站一张」。

## 五、脸的设计纪律(题侧)

1. **玩家八名词**:脸的文案与机制只许说 牌·花色·点数·张·秒·格·分·牌型;
   设计分类词(成长/引擎/使能)禁止上脸。
2. **禁令必须禁大家本来会做的事**:脸管的行为若自然频率接近零,题目不成立
   (拿 Tape 的行为基线筛)。同理:惩罚收不到的行为,别罚(零弃拍几乎不存在 ⇒ 罚零弃的脸空转)。
3. **软惩罚优先,硬禁必有解**;弃牌限制一律以**张**计,不以次计(多选弃牌让次数没牙)。
4. **随机决定多难/打哪个,不决定有没有玩点**;掷点开局当场明掷(动画),逐拍掷分只许卡侧。
5. **可解除只有两个合法形状**:累计量条件(单拍物理上完不成)或构筑相关成本
   (对某些构筑便宜=顺风,对某些贵=绕路)。单拍能白嫖解除的,死(「做就完了,不亏的」)。
6. **刻度是螺丝钉不是内容**:同机制不同数值合并成族(同图标 + 记号),不算新脸;
   内容感只来自新决策。
7. **高频小罚(叽歪型)压低上场率**,真人试玩定去留。
8. **一题多解**:每道硬题的解 ≥3 条、横跨 ≥2 条骨架;组合解不许是唯一解;
   对策不许是必需品(没抽到某张卡等于失败 = 违反「无必解」)。
9. **对同构筑的攻击面要对称掂量**:点数被遮几乎伤所有旗,花色被遮只伤同花——
   重的那张排后段或给温和拨盘。

### 脸的架构:机制 × 刻度 × 对象 × 算子 × 复合

- **机制是手写的稀缺资源**;刻度(严重度)、对象(打谁,可掷)、算子(概率掷/拍相/渐变/可解除)
  都是拨盘——**算子建一次模,全族覆盖**,新脸=新参数组合=零新代码,gate 自动覆盖。
- **拍相算子慎用**:要玩家记单双拍的,不自解释,死过两张。
- **复合的语法 = 乙脸封掉甲脸的最优解**(低音的解是狂弃刷小牌,配限弃封死这条路),
  不是随便两张异轴叠加;异轴、最多两成分、成分必须先单独登过场、**命名双名连写**(零学习成本)。
  后期关卡靠一段多盲注实现;纯压力叠加(无咬合)终盘留少数几对即可。
- **⚑ 扩池三轴(2026-08-26 用户补拍,治「盲注特别少」)**:
  ① **刻度档位要实例化上场** —— 「盲注是可以改数字的」:同机制的松/紧档各占一个登场位
  (纪律 6 说它们**不算新内容**,但**都是合法池条目**;同图标 + 档记号,零新代码,
  门对每档独立定价);
  ② **纯分数墙是合法脸型** —— 「纯粹的分数要求也是一种盲注」:零规则、只抬目标分
  (`raisedbar` 即孤例,该档位化成族 ×1.25/×1.5/×1.75…);它是序列里的**呼吸位**,
  也是「构筑本身够不够强」的裸测;
  ③ **复合**(见下条)。三轴相乘,池容量 = 机制数 × 档位 × 复合对,不再逐张手写。
- **序列即关卡**:一局的题是四张脸的序列;同轴不连发,难度形状对齐起承転結([`difficulty.md`](difficulty.md))。
- **开局亮整局四张脸**(定案候补,四条独立理由:调度解法的前提 · 换阵的物流 · 「先定型后遇敌」
  这个苦恼主因的解 · 构筑从第一次商店起就对着整局解题)。脸是开局掷定的,数据现成,只差公示。
- **玩家苦恼的治理分两端**:格子不均在设计端进预算带(杀伤宽度/受敌定价),在随机端靠序列杀伤
  预算与信息前置;**商店池权重不动**(拍板:不应该有任何卡有固定概率)——商店的公平靠价格
  与玩家侧方差工具(刷新/定金/换阵), 不靠暗手。

## 六、卡的设计纪律(答侧)

1. **卡面英文 ≤7 词,图即规则**(既有铁律,重申)。
2. **职能四分**:脊柱(接龙,必的组合)· 应变(随机应变的奖励)· 使能(创造拿到组合的条件)·
   顺应件(合法钥匙)。每张新卡先报职能再报数值。
3. **组合三纪律**:组合的两张各自能单用(概率放大器类豁免)· 每道硬题 ≥1 个破题组合但
   **没有组合破所有题**(射程必须有边界,否则是新的必买卡)· 组合不印卡面,靠结构涌现。
4. **链内冗余**:每条脊柱的放大层 ≥3 张可互换件,过关线=引擎+任意两件;桥件横跨两链;
   **顶点稀有=质变而非必需**(刷不到顶点不致死,否则制造最强的套路)。
5. **配合来自结构不来自标签**:亲和从「占用张数 → 自由牌」的数学涌现
   (牌型占得越少,自由牌越多,行为链越接得上),不印「与 X 配合」。
6. **成长只挂玩家主动行为,零挂机**(既有铁律);升级放大覆盖每个通道、金币通道不放大、
   规则牌不可升级(既有)。
7. **概率按期望定价,方差是产品**;玩家侧方差工具(刷新/弃牌)已是概率管理,足够。
8. **租赁 = 超额数值 + 短寿命**(只活一段/逐拍衰减),是换阵解法的润滑剂。
9. **无经营空间的被动条件不许发**(装上就忘、玩家无法朝条件努力的卡 = 无聊)。
10. **有最佳的家,但处处可用**:卡在最佳构筑里发光,在别的构筑里不废。

## 七、验证方案(本篇自带,按「验证跟着被验的东西走」)

| 验什么 | 怎么验 | 状态 |
|---|---|---|
| 三档推导 | 卡加「条件声明」字段,三档由条件×脸参数推导;`db.gd` 校验每脸「避开 ≥3 族、顺应 ≥1」 | 🔨 待实装 |
| 「必」字三查 | 无必买卡(单卡在获胜构筑出现率上限)· 无必解(每脸获胜骨架 ≥2)· 链无配方(同链获胜件组合有多样性);**延伸到双卡组合** | 🔨 sim 骨架归因待建 |
| 行为基线筛查 | 新脸入池前,Tape 里查它管的行为的自然频率 | 🔨 |
| 抵消半价审计 | 抵消类卡的补偿期望 ≤ 惩罚期望的一半上下 | 随定价 SOP |
| 禁令有效性 | 禁止型脸的解集清点(错开/利用/调度 ≥2 路) | 随池校验 |
| 杀伤宽度预算 | 每张脸「克多少条件族」落在带内——太宽降档/收窄, 太窄不占高档(格子不均要有价格) | 🔨 随三档推导 |

| 伏击率 | sim/Tape 同口径:构筑定型后遭遇 ≥2 张天敌脸的局占比——格子治理的成绩单 | 🔨 |
