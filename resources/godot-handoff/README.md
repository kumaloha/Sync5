# 霓虹玻璃卡片 — Godot 实现手册

游戏首页的核心视觉：一块无色透明玻璃卡，由场景灯光打出颜色。

## 素材文件（PNG，均带 alpha，黑底已抠透明）

| 文件 | 尺寸 | 内容 |
|---|---|---|
| card_glass_full.png | 842×1355 | 灰白玻璃卡 + 底部镜面倒影（推荐用这张） |
| card_glass_face.png | 842×1197 | 仅卡面，无倒影 |
| card_glass_pink_source.png | 842×1355 | 原始粉色版（未去色，备用） |

灰白版 = 原图 saturate(0) + brightness(1.06) 预烘焙，可直接用 `modulate` 或灯光上色。

## 关键几何（图像像素坐标，842 宽版本）

- 霓虹边框线：距左/右/上边缘各 40px，粗约 6-10px，圆角半径约 30px
- 卡面区域：y 0–1197；倒影区域：y 1197–1355
- 9-slice（NinePatchRect）切边：四边各 60px，中间 stretch
- 游戏内显示比例参考：0.76（即 842 → 640 显示宽）

## 分层结构（由下至上）

1. **内衬深底**：边框内侧 34px（显示像素）、圆角 18，线性渐变
   `rgba(13,15,34,.66) → rgba(6,8,20,.82)`（170°），可加轻微 blur
2. **玻璃贴图**：card_glass_full.png，`Modulate = 白色`（保持灰白）
3. **扫描线（可选）**：2px 主题色横线上下往返，透明度 0.7
4. **激光打色**：这是上色的关键 —— 卡体不带色，颜色来自灯
   - 左上角光源点：白色圆 + 主题色外发光
   - 两根激光：白色亮芯 2.5–3px + 主题色 glow，角度约 -26° 与 -37°（自竖直方向），长度穿过全屏
   - 沿光路一层淡雾锥（主题色 20–30% 透明度，blur ~24px）
   - **混合模式：Add / Screen**（Godot: `CanvasItemMaterial.blend_mode = BLEND_MODE_ADD`）
   - 整组缓慢摇摆 ±3.5°，周期 ~12s

## 关卡主题色（激光/描边/文字光晕用）

粉 #ff4fa3 ｜ 青 #35e8e0 ｜ 紫 #a56bff ｜ 橙 #ffb347 ｜ 蓝 #5fa8ff ｜ 红 #ff5f6e

透明度梯度用法：主题色按 alpha 0.2–0.9 派生（边框 0.7、光晕 0.4–0.6、淡雾 0.2）。

## 配套玻璃面板（顶栏 / 按钮，纯代码绘制）

- 边框：1px `rgba(主题色, 0.2)`，圆角 20–22
- 顶边高光：面板上缘一条 1.5px 白色亮线，两端渐隐，带主题色 glow —— 这是"被灯打亮"的关键细节
- 底面：`rgba(24,28,56,.34) → rgba(7,9,22,.42)`（近竖直渐变）+ 26px 间距点阵（`rgba(主题色,0.2)` 1px 圆点）+ 115° 斜向白色反光带（透明度 0.07）
- 卡内按钮（开始游戏）：同配方，边框 `rgba(主题色,0.7)`，内发光 `rgba(主题色,0.16)`

## 字体

Rajdhani（数字/英文）+ Noto Sans SC（中文），标题 700，正文 500-600。
文字发光：白字 + 主题色 text glow（0 0 12px 0.9 + 0 0 34px 0.5）。

## 背景

深蓝黑渐变 `#070a1a → #0a0d22 → #05060f`，168° 雨丝斜线纹理（透明度 ~0.1，向下滚动动画），少量主题色 radial 氛围光。
