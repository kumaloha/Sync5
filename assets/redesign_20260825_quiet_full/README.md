# Quiet Glyph full set

Complete isolated Direction A package: 63 Jokers and 33 Blind concepts. This
delivery is scoped only to `assets/redesign_20260825_quiet_full/`; pre-existing
worktree changes and all earlier redesign packages remain untouched.

## Contract

- Every master is a 1024×1024 PNG.
- All strong subject pixels stay inside the central `y=312..711` safe band.
- Joker subjects fit within 650×230; Blind subjects fit within 520×200.
- Flat muted glyphs, weak halo, no glass, bright cores, particle fields, scenes,
  prose, or incorrect score labels.
- One grouped subject plus at most one modifier.
- Blind concepts use muted dark-red outlines and remain pending a final
  monochrome-outline runtime pass.

## Review surfaces

- `contact_sheets/jokers_150.png` and `blinds_150.png`: exact 150px review.
- `contact_sheets/jokers_band.png` and `blinds_band.png`: exact runtime crops.
- `contact_sheets/jokers_vs_v2.png` and `blinds_vs_v2.png`: brightness/detail
  comparison with v2.
- `reports/luminance_comparison.json`: per-asset luminance measurements.
- `reports/safe_band_metrics.json`: per-asset safe-band measurements.
