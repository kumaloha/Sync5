# Quiet Glyph sample

Ten isolated Direction A samples: six Jokers and four Blinds. This package does
not modify v1, v2, or runtime assets.

- Masters: 1024×1024 PNG.
- Subject box: at most 650×230 for Jokers and 520×200 for Blinds.
- Central safe band: `y=312..711`.
- Style: flat muted glyphs, weak halo, no glass, particles, rays, prose, or
  bright cores.
- `sample_150.png` is the exact small-size review surface.
- `quiet_vs_v2.png` compares each quiet sample with its v2 counterpart.
- `reports/luminance_comparison.json` records mean-luminance ratios; every quiet
  sample is substantially dimmer than v2.
