# Joker + Blind visual redesign v2 — 2026-08-25

This delivery is scoped only to `assets/redesign_20260824_v2/`. It does not
replace `assets/redesign_20260824/`; pre-existing unrelated worktree changes
under runtime directories such as `assets/jokers/` and `assets/blinds/` are not
part of this package and were deliberately left untouched.

## v2 output contract

- 63 Joker masters in `jokers/joker_<id>.png`.
- 33 Blind concepts in `blinds_concept/blind_<id>.png`.
- Every master is a 1024×1024 PNG.
- Every strong subject pixel is contained in the central `x=0, y=312,
  width=1024, height=400` safe band.
- Source compositions were generated by the built-in image model, then
  proportionally normalized into a maximum 920×340 subject box without
  stretching.
- Joker art uses horizontal colorful poker metaphors with thick outlines.
- Blind art uses compact red/magenta warning silhouettes and remains at concept
  stage pending the final monochrome-outline approval pass.

## Review sheets

- `contact_sheets/jokers_full.png` and `blinds_full.png`: complete square masters.
- `contact_sheets/jokers_audit.png` and `blinds_audit.png`: safe-band overlays.
- `contact_sheets/jokers_band.png` and `blinds_band.png`: exact central runtime crops.
- `contact_sheets/jokers_150.png` and `blinds_150.png`: exact 150px-wide legibility previews.

## Validation

- `reports/safe_band_metrics.json` records the bright-subject pixel check.
- The final package is rejected if any strong subject pixel is outside the
  central band, any expected ID is missing, any PNG differs from 1024×1024, or
  any two final assets are byte-identical.
- `manifest.json` is the authoritative per-asset record.
