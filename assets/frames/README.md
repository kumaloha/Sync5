## 为什么交接件的 PNG 不能直接贴(2026-08-05 实测)

`resources/godot-handoff/` 的手册是权威、照做;但它附的 PNG **抠图是坏的**,
三个毛病逐个验证过:

1. **alpha 是坏遮罩** —— 辉光被硬边切断。4× 放大能看到轨外一圈方块状硬边
   (用户:「有毛边呀,没抠干净」)。
2. **辉光区 RGB 本身是噪点/抖动的** —— 用亮度重建 alpha 后硬边没了,
   露出一团麻点;降采样去噪后,又露出辉光形状本身是**不规则云团**,
   不是围着圆角矩形的干净光晕(AI 生成烘死在像素里)。
3. **玻璃体内部被抠烂** —— 全图 40% 的像素原遮罩与亮度对不上。
   小尺寸/深色背景能盖住,**首页大卡尺寸下是一大片云状污块**,藏不住。

轨和外框是干净的,坏的是内部和外圈雾 —— 而那两块恰好是玻璃的主体。
所以最终按手册**程序化画**(尺寸无关,顺带解决扁板 560×276 的比例问题)。

要换素材的话:内部必须干净、alpha 是真透明(不是抠出来的),
比例接近 2:3,自带下方倒影更好(首页靠它兜住页签)。
