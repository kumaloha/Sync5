### 1.2 Inference

动作空间(机制, 非策略):持牌头 C(8,5)=56 → 弃牌头 2^5−1 掩码 ∪ {停}(预算内合法)
→ 补牌后循环, 停或预算尽则 lock;商店头阶段②。

★★ **「预算内合法」里的预算必须包含「每拍动作次数」, 不能只有金币**(v2.2 新增, 关键):
`core/phrase.gd:42` 的 `can_discard` **只查金币**, 机制上对每拍弃牌次数零上限;
现在唯一在把关的是 `bot.gd:371` 手写的 `cap = 3 if dur >= 12.0 else 2` ——
**而那正是 16 §5 要退役的「判断」**。一旦删掉它, 新 bot 开局 6◆ 就能合法弃 5 张、
补牌再弃, 而 (F2) 是**不死局 + 纯分数**目标、sim 里又没有时钟, 反向压力只剩「钱要留着买牌」。

折成**每拍动作点数预算**写进 `data/run.json`, 由 `core/phrase.gd` 执行(不是 bot),
φ27 暴露「本拍剩余预算」。这条不做, D-① 的产出不可用。

### 1.3 目标函数(三个阶段各一个)

**阶段一 · 能力**(最大化):

```
(F2)  J(θ) = E_{c~U(队列), ω, a~π_1} [ Σ_{s=1..4} ln(1 + Score_s) ] − λ‖θ‖²
```

- 期望所在的随机性 ω = (牌堆种子, 货架抽取, 脸掷点) + softmax 抽样;λ = 0.01。
- 回报取 **log 段分**:与 G 的 log 空间同尺度, 且比通关率稠密(0/1 信号方差大);
  **回报尺度**与 T 无关(T 膨胀不会把 fitness 一起吹大)。
- ★★ **v2.1 的「fitness 与 T 无关」是错的, v2.2 撤回**(对抗审查 blocker-1, 已在代码验证):
  **缺口 = `core/run.gd:77 deficit() = target() − section_score` 就是 T 的函数**,
  而缺口是 **φ17, 还乘进 φ21..φ24 四个交互项** —— T 不是从「死亡截断」那条暗道进来的,
  是从**特征向量正门**走进来的。而且**删不掉**:`design/history_adversarial.md` §5 明写「『缺口大要赌』这类行为
  由优化自己学出来, 不写死」—— 缺口是设计要的特征。
  所以:**scale-free 回报只挡住了「追分数膨胀」, 挡不住「追移动靶」。**
- ★★ **防移动靶的真正机制 = 训练期冻结 T_train + θ/ψ/T 整组换版**(从 §3「兜底」升为**主机制**):
  ① 一次 CEM 训练全程用同一份 T_train, 中途不换;
  ② T 有实质变化后 **θ 必须重训**(warm-start), **不允许只换 T 留旧 θ** ——
     旧 θ 的缺口读数是对着旧靶盘学的;
  ③ 仍保留**不死局**评估(封掉死亡截断这条**另一条**通道, 与本条正交, 两条都要)。
- 估计:Ĵ = M 局样本均值, 六个单 target 队列均匀轮换。

**阶段二 · 拟人-A(有真机行为日志, 最小化)**:

```
(F3)  L_BC(θ) = − Σ_{(s,a)∈真人日志} ln π_1(a|s) + λ‖θ‖²
```

**阶段二 · 拟人-B(只有结果分布, 最小化;先只动 w_τ, θ 冻结)**:

```
(F4)  L_pop(w) = Σ_{b∈{死S1..死S4, 通关}} ( Σ_τ w_τ·q̂_b^(τ) − q_b^真人 )²
                + λ₁‖弃牌率矩差‖² + λ₂·KL(牌型分布‖真人)
      s.t. w ≥ 0, Σ w_τ = 1
```

★ 口径:q̂ 取**无条件死亡份额**(死在 S1..S4 / 通关, 五格和 = 1;份额 = reach·(1−p)),
混合即 Σ w·份额, 对 w **严格线性** → 主项是**单纯形上的凸最小二乘**, 不用碰 θ。
16 §1 的**条件**死亡率(到达者口径)混合时分母里也有 w(幸存者重加权 F10),
线性与凸性都会破——设计镜头(死亡聚墙)照旧看条件谱, 仅 (F4) 拟合换无条件口径,
两口径信息等价、可互换算。θ 重训(用 F3 或把 F4 当黑盒 fitness 丢回 CEM)
只在 w 调不平时发生。

### 1.4 Backward

**A0 · 初始化 = 对规则 bot 行为克隆。** 规则 bot 的 (s, a) 日志免费(跑 sim 就有,
动作机械映射进新动作空间), 用 (F3) 的梯度下降得 θ₀。
★ 但克隆 loss 低 ≠ 表现打平——规则 bot 的多拍追牌计划未必线性可分,
θ₀ 的 sim 表现要**实测入档**, 不当前提;打不平也没关系, CEM 从最近的起点爬,
「≥ 规则 bot」以 §5 的终点验收为准。

**A · CEM(能力阶段主路线)**:

```
初始化: μ₀ = θ₀(A0) 归一到单位球面, σ₀_j = 0.3·|θ₀_j| + 0.05   ★★ 相对量, 不是绝对 0.3
每代 t:
  1. 抽 θ_i ~ N(μ_t, diag(σ_t²)),  i = 1..N=100          ★★ 24 → 100
  2. 公共随机数 CRN:本代所有候选用同一组 M≈48 局种子     ★★ 200 → 48(同预算重切)
  3. F_i = Ĵ(θ_i)                        ← (F2) 的样本估计
  4. elite = F 前 25%(K=25)                              ★★ 6 → 25
  5. μ_{t+1} = mean(elite);  σ²_{t+1} = c·var(elite) + σ_min²,  c > 1, σ_min = 0.02
终止: 15 代 elite 均值无提升 > 0.5%, 或 60 代
     ★★ 末期噪声守卫:精英前两名差距 < 2×标准误时, 本代 M 翻倍重评
产出: ★★ 历史最优 **前 5 名**各用 M′=1000 局重评取最优(v2.1 只重评 argmax ——
     那能**检测** winner's curse 却不能**纠正**它, 真正的最优常是历史第 3 名;
     成本 5×1000 局可忽略)
```

★★ **三处改动的理由**(对抗审查 R1/R2):
① **同预算下 N=24/M=200 是最差的一档切法**:固定 N·M=4800/代, 残差 ‖μ−θ*‖²
   N24/M200 = −0.111 / N100/M48 = −0.051 / N200/M24 = −0.034(从 ρ_CRN=0.9 到 0
   及病态景观下结论一致)。**次优不是错误**, 但白扔 2–3 倍。
② **K=6 会让 σ 在第 25 代撞底**:精英样本方差的 Jensen 偏倚使 σ 每代乘 0.899
   (`E[ln s²] = ψ((K−1)/2) + ln2 − ln(K−1) = −0.213`, MC 复核 −0.212),

### 2.3 目标函数(两个拟合 + 一个根求解)

**主拟合(最小化, 有闭式解)**:

```
(F11) L_fit(ψ) = Σ_i ( y_i − ψ·x_i )²         (i 遍历遥测行, ~3.6 万条/批)
```

**方差校准(最小化, 每队列一维)**:

```
(F12) L_cal(γ_c) = Σ_s ( p̂_{c,s}(γ_c·σ_c) − p^obs_{c,s} )²
```

**生成(根求解, 不是优化)**:逐段解 `D_s(T_s) = d*_s`(D_s 对 T 单调 → 二分;
先解 T₁ 定权重再解 T₂…)。单队列退化为闭式 `T = exp(μ + σ·Φ⁻¹(d*))`。

### 2.4 Backward

```
1. 遥测装 (X, y);ψ* = argmin‖y − Xψ‖²    ← (F11)
   ★★ **解法不用正规方程 + Gauss-Jordan**:XᵀX 把条件数**平方**, 而设计矩阵本就

2. σ_c = 队列内残差标准差

   ★★ **网格 {0.8..1.4} 太窄, 改 {0.6 .. 3.0}**(对抗审查 H7):(F8) 代**单点** x̄ 得到的是
   「特定 x 下」的过段率, 而队列过段率要**对 x 分布积分**, 丢掉的组间成分是 `ψᵀΣ_xψ`。

```

★ 换版补一条:θ 或 T 换版后**重采遥测再拟合**——装配轨迹/金币等 x 的经验分布
